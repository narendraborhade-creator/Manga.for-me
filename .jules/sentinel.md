## 2026-10-30 - SSRF Wildcard DNS Rebinding & Embedded Private IP Bypass
**Vulnerability:** The image proxy's target URL validator `isValidProxyTarget` validated IPv4 octets and hostname strings for `localhost` and private IP addresses directly, but allowed wildcard DNS services (such as `nip.io`, `sslip.io`, `localtest.me`, `vcap.me`) and domains embedding private/loopback/cloud metadata IP patterns (e.g., `127.0.0.1.nip.io`, `169.254.169.254.nip.io`, `127-0-0-1.sslip.io`). These domains resolve dynamically to `127.0.0.1`, `169.254.169.254`, or private RFC1918 addresses, bypassing static hostname inspection.
**Learning:** URL string validation on `url.hostname` alone does not prevent DNS-level resolution to loopback or cloud metadata IPs if wildcard/rebinding DNS domains are allowed.
**Prevention:** Explicitly deny known wildcard DNS resolution services (`nip.io`, `sslip.io`, `localtest.me`, etc.) and block hostnames with embedded private, loopback, or cloud metadata IPv4 addresses (`127.*`, `10.*`, `169.254.*`, `192.168.*`, `172.16-31.*`).
