## 2024-06-25 - React Multiple Statistics Iteration
**Learning:** In React components like `LibraryView.jsx`, iterating multiple times over large collections to compute grouped counts (e.g. using 6 different `.filter().length` calculations) inside a render cycle creates an O(N*M) bottleneck which degrades UI performance as the collection size grows.
**Action:** When calculating grouped counts/statistics, always consolidate multiple `.filter().length` loops into a single O(N) `.reduce()` traversal, and wrap it in a `useMemo` block. Ensure not to memoize volatile local storage variables directly unless wrapped correctly in state or recalculated per render.
