## 2023-11-09 - Avoid Proxy Dependencies for Local Storage Reads
**Learning:** In React components that read synchronously from `localStorage` (like `getHistory` and `getUpdates`), it is dangerous to memoize those reads using an unrelated prop (like `bookmarks`) as a proxy dependency. This anti-pattern prevents the component from re-fetching the latest external data when the external data changes independently of the proxy dependency, leading to stale UI.
**Action:** Do not wrap synchronous local storage read functions in `useMemo` unless you have a robust subscription mechanism (like `useSyncExternalStore`). Only memoize the *subsequent* expensive operations (like filtering or mapping) that rely on the fetched data.
